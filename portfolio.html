Descontou+
O Descontou+ é um site desenvolvido como protótipo de um clube de descontos online. O objetivo do projeto é simular uma plataforma onde usuários podem se inscrever gratuitamente para receber promoções exclusivas em produtos e serviços. O site conta com páginas estruturadas em HTML, estilização em CSS e interatividade em JavaScript, incluindo formulário de inscrição, área de depoimentos, seção de perguntas frequentes e design responsivo.
To-do List
O To-do List é uma aplicação web desenvolvida para organizar tarefas de forma simples e eficiente. O usuário pode adicionar novas tarefas com título e descrição, marcar como concluídas, editar o status por meio de checkboxes e excluir quando desejar. O sistema utiliza localStorage para salvar os dados, garantindo que as informações permaneçam mesmo após fechar o navegador. O projeto foi implementado com HTML, CSS e JavaScript, com foco em boas práticas e usabilidade.
